# String utilities. Unless stated otherwise, they take a STRING and return a STRING.
#
# BLANKS (STXT-SPEC §4, since 2026-08-21). Everywhere in this file and in the core, "blank"
# means exactly two characters: SPACE (U+0020) and TAB (U+0009). Every trim, right trim,
# "is the line empty?" test and separator run below works on those two characters ONLY.
# Any other Unicode space (U+00A0 NBSP, U+3000, U+2028, ...) and any control character is
# content. A port MUST NOT use its platform's generic trim/strip/isWhitespace, which are
# broader (JS String.trim and Python str.strip remove all Unicode space; Java String.trim
# removes every code point <= U+0020). Conformance pair: conformance/tree/nbsp.
BLANKS = " " + TAB

# Canonical node name (STXT-SPEC §4.3). Diacritics and non-Latin letters are KEPT:
# name equality is insensitive to case and separators, but sensitive to accents and
# alphabet, following the IDN model. E.g. "Caña" == "caña", but "Caña" != "Cana".
#
# Process:
#   1. trim() (blanks only)
#   2. Unicode NFC normalization (precomposed and decomposed forms become equivalent)
#   3. Unicode lower case, locale-independent (NOT full case folding: 'ß' is kept and
#      differs from 'ss'; STXT-SPEC §4.3)
#   4. Every run of separators ('-', '_', blanks) becomes a single '-'
#   5. Leading and trailing '-' are removed
#
# May return the empty string (e.g. for "___"): the caller MUST treat that as a
# parse error (STXT-SPEC §4.3, §11.7).

END FUNCTION
